# Language icons

This directory contains local SVG copies of language and developer-tool icons from [Devicon](https://github.com/devicons/devicon).

The files are stored in the repository so the profile language-statistics generator can use local assets instead of downloading icons during each GitHub Actions run.

## Files

SVG files in this directory are copied from Devicon's `icons/<name>/<name>-original.svg` paths. Some technologies do not have a distinct language logo; for example, GDScript is represented by the Godot logo.
